Чат на сокетах

Простой чат-сервер на Python

Используется TCP-соединение и библиотека socket

Для одновременной работы нескольких клиентов используется threading

Файлы проекта:

server.py - сервер

client.py - клиент

protocol.py — протокол сообщений

Запуск:

Сначала запустить server.py

Потом открыть два или больше терминалов и запустить client.py

Команды:

/list - показать список пользователей.

/quit - выйти из чата

Обычный текст отправляется другим клиентам

Протокол:

COMMAND + LENGTH + DATA

COMMAND занимает 4 байта

LENGTH занимает 4 байта

DATA содержит данные сообщения

Для длины используется struct.pack("!I", size)

Для получения данных используется функция recv_exact()

Максимальный размер сообщения 10 MB

Команды протокола:

JOIN - подключение пользователя

TEXT - отправка сообщения

LIST - список пользователей

QUIT - выход пользователя

Сервер обрабатывает обычное и неожиданное отключение клиента

Если один клиент отключается, сервер продолжает работать
